{{- /* Galerie du projet. Selection et ordre des images, dans cet ordre de priorite : 1. le champ `galerie` de l'entete, liste explicite de noms de fichiers du page bundle. Il fait autorite : c'est le seul moyen de choisir un sous-ensemble ou un ordre qui ne suit pas les noms de fichiers ; 2. a defaut, toutes les ressources image du bundle, moins la couverture. Ce repli est le cas courant : deposer les images dans le dossier suffit a les publier. L'ordre est alors celui des noms de fichiers, d'ou la numerotation a deux chiffres decrite dans le README. Rendu : une grille de vignettes carrees. Le jeu d'images d'un projet melange paysage et portrait, dans des rapports tres eloignes (3/2 et 2/3). A rapport conserve, une ligne de grille se cale sur la plus haute image et laisse de larges vides sous les paysages, faute de disposition en maconnerie sans JavaScript. Le carre recadre au centre donne une trame reguliere, et rien n'est perdu : chaque vignette ouvre l'image entiere, dans son rapport d'origine, en 1600px de large. Pas de lightbox, pas de JavaScript : la vignette est un lien vers un fichier image, qui fonctionne aussi bien sans script que dans un nouvel onglet. Le lien tire son nom accessible de son aria-label. L'image porte un alt vide sauf si la ressource declare un titre explicite dans l'entete : le nom de fichier n'est jamais un texte alternatif. Rien n'est rendu si le projet n'a aucune image hors couverture : l'appelant teste la sortie pour ne poser ni filet ni conteneur vide. */ -}} {{- $page := . -}} {{- $images := slice -}} {{- with .Params.galerie -}} {{- range . -}} {{- with $page.Resources.GetMatch . }}{{ $images = $images | append . }}{{ end -}} {{- end -}} {{- else -}} {{- $exclu := "" -}} {{- with partial "couverture.html" $page }}{{ $exclu = .RelPermalink }}{{ end -}} {{- range $page.Resources.ByType "image" -}} {{- if ne .RelPermalink $exclu }}{{ $images = $images | append . }}{{ end -}} {{- end -}} {{- end -}} {{- $titre := $page.Title -}} {{- if not $titre }}{{ with $page.File }}{{ $titre = humanize .ContentBaseName }}{{ end }}{{ end -}} {{- with $images }}
